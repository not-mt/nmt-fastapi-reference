# Agent Instructions

This repo is the backend API reference and architectural model for related FastAPI apps; reuse nmtfast for shared cross-app infrastructure.

For Python standards & conventions, see `docs/PYTHON.md`.

For commands related to testing and linting, see `docs/TESTING.md`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo: `CONTEXT.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
